# Agricultural_Classification_GEE
Personal codes for processing Sentinel 1 and 2 image collection and also PlanetScope images for an Agricultural Landcover classification. Currently the study area is the northern regions of Tanzania but would extend to Rwanda as well.
I used a random forest classification algorithm for the classification. The training data was split in a 70:30 ratio with the 30% serving as validation data later on in the classification
The PlanetScope images were downloaded from the PlanetScope platform and uploaded to Goodgle Earth Engine (GEE). GEE was used to process the classification.
